# Relais 14 — v79 : fiche « ? » complète pour chaque exercice (Claude → Codex)

Brief de Sid : bouton « ? » sur chaque exercice → 2 photos (départ + arrivée/phase clé, même variante et matériel, droits vérifiés, provenance/licence gardées, pas de doublon ni de visuel générique, pas d'illustration générée présentée comme photo) + conseils FR/EN propres à la variante (placement, exécution, respiration, points d'attention, erreurs ; sources fiables ; rien de médical). « ? » partout : catalogue, aperçu de programme, séance active, remplacement/sélection, programmes perso et importés reconnus ; aide sans perte de saisie ni minuteur ; accessible (nom, clavier, focus rendu, Échap), images optimisées, alt, chargement, erreurs. Non reconnu : pas de fiche approximative, association explicite proposée, absence signalée, données gardées, jamais de « ? » vide. Anti-régression : un exercice sans fiche complète est refusé ou marqué incomplet avant d'entrer dans la génération. Tests automatiques + vérification visuelle + revue croisée. **Pas de publication sans accord.** Ne pas déclarer « complet » s'il reste un trou.
